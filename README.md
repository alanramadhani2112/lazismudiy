## Tracked Code

This repository tracks custom project code only:

- `wp-content/themes/lazismu-diy`
- `wp-content/plugins/lazismu-core`
- `wp-content/plugins/lazismu-donation`
- `wp-content/plugins/lazismu-zakat`

- Project documentation files

WordPress core, uploads, and local config are ignored.
